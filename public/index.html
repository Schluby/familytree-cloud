Sauvegardes

Tout ce que vous modifiez est écrit dans la sauvegarde active, tout de suite. Clic droit : renommer, dupliquer, télécharger.

    Vues

      Joueurs

      Cliquer un joueur : les cartes prennent la couleur de son humeur et la liste de droite s’édite d’un clic. Clic droit : modifier.

        Liens

        Un clic isole un type, les suivants l’élargissent. Clic droit : nom, couleur, trait, sens.

          Filtre

          Maisons — un clic isole une maison, un clic droit la modifie.

            Options

            Édition

            • Clic droit sur une fiche : ouvrir, relier, supprimer.
            • Clic droit dans le vide : nouveau profil.
            • Poignée ＋ sous une fiche : glisser vers une autre pour créer un lien.
            • Maj + clic sur deux fiches : les relier sans quitter la vue.
            • Ctrl + glisser une fiche : la repositionner à la main.
            • Clic sur un lien : changer son type et son humeur.

            Sur téléphone, l’arbre se consulte : le clic droit et le glisser n’ont pas d’équivalent tactile. Pour modifier, ouvrez la page sur un écran large.
